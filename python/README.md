# E-Commerce Sales & Customer Analytics

## Project Overview
This project analyzes e-commerce transaction data to understand revenue trends, product performance, and customer purchasing behavior.

## Tools Used
- Python (Pandas)
- MySQL
- Microsoft Excel
- Power BI

## Key Analysis
- Total revenue and order analysis
- Monthly revenue trends
- Top 10 products by revenue
- Top 10 customers by revenue
- Customer purchasing behavior

## Dashboard
The Power BI dashboard includes revenue and order KPI cards, a monthly revenue trend, and top-product and top-customer charts.

## Business Value
The analysis helps identify strong-performing products, high-value customers, and changes in monthly sales performance.

## Skills Demonstrated
Data cleaning, exploratory data analysis, SQL queries, data visualization, KPI reporting, and business insight generation.
